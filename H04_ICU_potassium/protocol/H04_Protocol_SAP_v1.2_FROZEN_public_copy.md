## 1. 题目与研究性质【已批准】

**工作题目**：成人 ICU 中近同时测得的血气全血钾与中心实验室钾的一致性及其在临床界值上的分类不一致——MIMIC-IV 主分析与 SICdb 补充分析。

- 配对来自不同 specimen 的近同时记录，结论限定为“真实工作流中记录时间相近、不同标本的结果”。
- 不作因果解释。

## 7. 主要指标【已批准】

三分类：cat(x) = 1（x < 3.5）、2（3.5 ≤ x ≤ 5.0）、3（x > 5.0）。

**主要指标** = 所有配对中 cat(G) ≠ cat(L) 的比例，附 95% CI（第 10 节）。

界值依据：
- 参考区间 3.5–5.0 mmol/L，见 Kardalas 2018（Endocr Connect 7:R135，“Definition and prevalence of hypokalemia”节）；
- 与 Nakhil 2026 的分类定义相同：异常为 K⁺ >5.0 或 <3.5 mmol/L（Methods）。

两处均已读全文。

## 8. 关键次要指标【已批准】

1. **界值 c ∈ {3.0, 3.5, 5.0, 5.5, 6.0}**：
   - 异常定义：c = 3.0、3.5 时 x < c；c = 5.0 时 x > 5.0；c = 5.5、6.0 时 x ≥ c。
   - 对每个 c，分母为全部配对，报告：
     - “血气异常、实验室未异常”比例 = P(A_G ∧ ¬A_L)；
     - “实验室异常、血气未异常”比例 = P(A_L ∧ ¬A_G)。
   - 措辞对称，不称敏感度、漏诊或假阳性。
2. **条件比例**（两者并列）：
   - 以实验室分层：P(¬A_G | A_L) = #(A_L ∧ ¬A_G) / #A_L；
   - 以血气分层：P(¬A_L | A_G) = #(A_G ∧ ¬A_L) / #A_G。
   - 注明向均值回归。
3. **Cohen kappa**（三分类、无权重）：κ = (p_o − p_e) / (1 − p_e)，其中 p_o 为对角线比例，p_e = Σ_k p_G,k · p_L,k；p_e = 1 时不可估。不报 PABAK。
4. **界值出处**：
   - 3.5、5.0 见第 7 节；
   - 3.0 见 Kardalas 2018 Table 3（轻度低钾 3.0–3.4，中度 2.5–2.9）；
   - **5.5、6.0【出处待核】**：拟引英国肾脏协会（UKKA）成人高钾血症指南，原文本轮未能取得（官网链接超时或 404）。界值按 G1 设计照常预设。出处核实前，论文称“本研究预设的数值界值”，不写“依据某指南”，也不称“常用”（第 26 节 J3）。
5. **按均值区间分层的不一致比例**【G4 确认，起草者建议保留】：
   - 按 cat(M) 分三层，分别报告 cat(G) ≠ cat(L) 的比例与 CI；
   - 只作描述，注明 M 与 G、L 数学耦合，不作推断。

## 9. 一致性分析【已批准；实现细节 G4 确认】

所有计算配对等权，除 S6 外。分位数默认 R `quantile(type = 7)`。

1. **中心**：mean(D)。
2. **(b) 经验 LoA（主要解释依据）**：
   - 主报告：q₀.₀₂₅(D)、q₀.₉₇₅(D)，type 7；
   - 另报 type 1（逆经验分布），供与 S6 比较。
3. **(a) 模型型 LoA（补充）**：
   - 模型：`lme4::lmer(D ~ 1 + (1 | patient), REML = TRUE)`；
   - LoA = β₀ ± 1.96·√(σ²_b + σ²_w)；
   - 依据：Bland & Altman 2007（作者版 PDF 第 6–7 页，全文已读）的思想——差值 = 偏倚 + 受试者间随机效应 + 受试者内误差，单次差值方差 = 两方差分量之和。原文用方差分析估计；本研究用 REML 混合模型，属本 SAP 的实施选择，不称已由原文逐项验证。
   - 模型中心 β₀ 是 REML 固定截距，与第 1 条的简单均值 mean(D) 不是同一量，两者并列报告。
   - 前提：随机截距与残差均近似正态；患者内方差同质；配对次数与患者差值分布无关。在这些前提下，它近似描述单个配对差值的 95% 范围，不是对新患者的条件预测；前提不成立时不声称有 95% 覆盖。
4. **(c) 回归型 LoA（次要）**：
   - 模型：`lmer(D ~ M + (1 | patient), REML = TRUE)`；
   - LoA(m) = a + b·m ± 1.96·√(σ²_b + σ²_w)；
   - 评估点 {3.0, 3.5, 4.0, 5.0, 5.5, 6.0} 中，只报告落在原样本 M 的第 1–99 百分位（type 7，含端点）之间的点。
   - 这是本 SAP 预设的回归型扩展；Bland & Altman 1999 原文未读，不称其精确实现已由原文验证。
   - 前提：随机截距与 M 无关；残差同方差且近似正态。它只描述“平均差随 M 线性变化”的情形，不能处理异方差。
5. **(d) 分组经验 LoA（次要）**：
   - 切点 t₁ = q₁/₃(M)、t₂ = q₂/₃(M)（type 7；按精确的 1/3、2/3 计算，v0.7 文字写作第 33.3、66.7 百分位，见差异表 D15）；
   - 分组：M ≤ t₁；t₁ < M ≤ t₂；M > t₂；
   - 每组报告 q₀.₀₂₅(D)、q₀.₉₇₅(D)；
   - 原样本：t₁ = t₂ 或任一组 <10 对时，三组都写“不可估”。
   - 重抽样：t₁ = t₂ 时三组都记“不可算”；否则只把 <10 对的那一组记“不可算”（恢复 v0.7 第 10 节表格的规则）。
6. **模型不收敛的判定**：
   - 判为不可用：拟合报错；lme4 给出除“boundary (singular) fit”以外的任何警告或信息（包括设计矩阵秩亏而删列的提示）；优化器返回码 ≠ 0；任一系数或标准误非有限。
   - 奇异拟合（σ²_b = 0）保留。
   - 原样本不收敛时，点估计与 CI 都写“不可估”。
7. **分布诊断**：QQ 图，包括原始差值、(a) 与 (c) 的条件残差。只作描述。
8. **S6（每名患者等权）**：
   - 中心 = 各患者差值均值的均值；
   - LoA = 加权逆经验分位数，权重 w = 1 / 该患者配对数，取累积权重首次 ≥ q 的差值；
   - 不做 (a)、(c)、(d)。
9. **Passing–Bablok（只在 S2）**：
   - 实现：`mcr::mcreg(x = L, y = G, method.reg = "PaBa", method.ci = "analytical", alpha = 0.05)` 取点估计（截距、斜率），mcr 版本 1.3.3.1；
   - CI：按配对有放回重抽样 1,000 次，种子 20261110；每次重新调用上式取点估计；百分位法 95% CI（type 7）。用自写循环而非 mcr 内置 bootstrap，以便记录不可算次数。
   - 重复值：按 mcr 的 PaBa 实现处理，不另作处理；退化样本未经专门验证（合成测试只覆盖常数值不致中断）。
   - 重抽样中报错、状态不合格或截距/斜率任一非有限，记该次为不可算（截距与斜率一并记）；不可算 >1%（>10 次）时 CI 写“不可估”；原样本不可算时点估计也写“不可估”。
   - **Cusum**：只报告 `calcCUSUM` 返回的 `max.cusum`（本机 mcr 1.3.3.1 源码中的字段名；手册写作 max.cumsum，以源码为准，证据见 `06_audit\2026-11-11_G4_冻结前核对\mcr_calcCUSUM_source.txt`）及正负残差数。判据须出自 Passing–Bablok 1983 原文（未取得），因此**不作线性与否的判断**（第 26 节 J2，删去 v0.7 要求的检验判断，待批准）。

## 10. 置信区间【已批准；实现细节 G4 确认】

1. **患者整群自助法**：
   - 设 P 为该分析集中的患者数；每次从 P 名患者中有放回抽取 P 名，被抽中多次的患者视为不同的簇、重新编号，拼接其全部配对；
   - B = 2,000 次；
   - 随机数：R `RNGkind("Mersenne-Twister", "Inversion", "Rejection")`，每个分析集开始前 `set.seed(20261110)`。
2. **每次重抽样重算**该分析集的全部估计量：
   - 主分析集 P 含 (a)(c)(d) 与 S6；
   - (d) 的切点每次重算；
   - (c) 的评估点沿用原样本判定。
3. **CI 计算**：
   - 百分位法：可算值的 q₀.₀₂₅、q₀.₉₇₅（type 7）；
   - “可算”= 状态合格且数值有限；NA、NaN、Inf 一律记为不可算；
   - 某估计量不可算（分母为 0、p_e = 1、模型不可用、分组退化、非有限）的次数 >1%（>20 次，严格大于）时，报告点估计，CI 记为“不可估”，并报告不可算次数；原样本不可算或非有限时，点估计与 CI 都写“不可估”；
   - 不用忽略聚类的方法代替。
4. 比例为 0 或 1 的重抽样结果保留。
5. **小分子**：比例的分子为 1–9 时，点估计和 CI 都不报，只写“<10”（项目输出规则，第 17 节）。

## 11. 相关因素（探索性关联描述，非因果）【已批准；实现细节 G4 确认】

1. **分析集**：只在两库的主分析集（10 分钟窗全部配对）中做，敏感性分析集不做（第 26 节 J7）。
2. **结局**：
   - 差值模型：D；
   - 分类不一致模型：cat(G) ≠ cat(L)（0/1）。
3. **候选变量**：pH、白细胞、血小板、肌酐、葡萄糖、标本类型、带符号采血时间差、ICU 类型（仅 MIMIC）。
   - 缺失 >50% 的变量从一开始就排除；
   - 每一步按当时的变量集合取完整病例；
   - 报告完整病例与非完整病例在单一来源变量上的比较（实验室钾、血气钾各自、各协变量的四分位数，类别变量的计数），不涉及钾差值（恢复 v0.7 第 11.8 节）。比较做两次：按初始候选变量集合一次；对每个最终拟合的主模型（差值 LMM、不一致 GEE）按其最终变量集合各一次。
4. **类别变量参照**：
   - 标本类型以 ART 为参照；完整病例集中没有 ART 时，该步视为设计失败，按第 7 条简化（不另选参照）；
   - ICU 类型以该完整病例集中配对数最多的类别为参照（只依据单一变量的计数，与结局无关）。
5. **样条**：连续变量用自然三次样条：
   - `splines::ns(x, knots = q₀.₅, Boundary.knots = c(q₀.₁, q₀.₉))`，type 7，按当前完整病例集计算；等价于 3 节点的限制性立方样条，2 个参数；
   - 三个节点不全不同时改为线性。
6. **参数个数 p**：样条 2，线性 1，类别变量为水平数 − 1。
   - 差值模型要求：患者数 ≥ 10p；
   - 不一致模型要求：较少类别的配对数 ≥ 10p；有不一致的患者 ≥ 10p；无不一致的患者 ≥ 10p。“有不一致的患者”= 在当前完整病例集中至少有一对不一致的患者；“无不一致的患者”= 在当前完整病例集中所有配对都一致的患者。
7. **固定简化顺序**（每步重定完整病例集、样条节点和 p，再检查第 6 条）：
   - ① 全部样条改线性；
   - ② 配对数 <500 的 ICU 类型并入“Other”；
   - ③ 依次删除 ICU 类型 → 带符号时间差 → 标本类型 → 葡萄糖 → 肌酐 → 血小板 → 白细胞 → pH；
   - ④ 只做描述。
8. **模型**：
   - 主：`lmer(D ~ X + (1 | patient), REML = TRUE)`（差值）；`geepack::geeglm(disc ~ X, id = patient, family = binomial, corstr = "exchangeable")`（不一致；数据按患者排序）。
   - 敏感性：S8 `lmer(D ~ X + (1 | patient) + (1 | stay))`（SICdb 用 case）；`lme4::glmer(disc ~ X + (1 | patient), family = binomial)`。
   - 敏感性模型使用对应主模型最终那一步的变量集合与完整病例集，不单独简化，以保证可比；主模型未拟合时不运行。
9. **失败出口**（v0.7 第 11.9 节，补写判定方法）：
   - 拟合前检测：设计矩阵秩亏（QR 秩 < 列数）、单水平类别、零方差变量；不一致模型另用 `glm` 作数值风险检查：出现“fitted probabilities numerically 0 or 1”或不收敛警告、`converged` 为假、或系数非有限。这是**保守的数值风险规则，不是分离的确证**，可能拒绝少数本可估计的模型（差异表 D16）；不用与单位有关的系数大小阈值。任一出现视为该步失败，按第 7 条简化，不允许软件自行删列；
   - GEE 报错、返回错误码或系数/稳健标准误非有限时，改用独立工作相关；仍失败，按第 7 条简化；
   - 混合模型不可用（判定同第 9.6 节）时，按第 7 条简化；奇异拟合保留并报告；
   - S8 不可用时，去掉 stay 层即回到主差值模型，S8 记为“不可估”；GLMM 不可用或分离时记为“不可估”；
   - 每一步先按当时的变量集合取完整病例并计数，**在构建设计矩阵之前**检查：完整病例 <200 对，或有不一致的患者 <50 名，则该模型**不输出推断结果**（恢复 v0.7，不再继续简化，也不因设计失败而绕过）；
   - 按固定顺序删到没有协变量（第 7 条第 ④ 步），或全部候选变量因缺失 >50% 被排除：只做描述，**不拟合仅含截距的模型**，不输出系数；
   - 简化到第 ④ 步仍无可用模型时，不输出推断结果；
   - 每一步的失败原因、完整病例数、参数个数都记录在结果中。
10. **输出**：
    - 系数、标准误、Wald 95% CI（GEE 为稳健标准误）；
    - 所用变量、所在简化步、相关结构；
    - 完整病例数、患者数；
    - 每个候选变量的缺失数。
    - 只写“与较大差值或不一致相关”。
