## 0. 通用规则（沿用冻结 SAP，除非本节另写）

1. 配对、主分析集：与 AN_r1 相同（读入与有效性检查照搬 an_01_main_v5.R 的 read_pairs 规则；主分析集 P = 10 分钟全部配对，n = 23,357，患者 8,797；脚本断言精确相等，否则停止）。
2. 分类：`cat3`、界值规则同 SAP §7–8：实验室钾 ≥6.0 指 lab ≥ 6.0（记录精度，不取整）。
3. 置信区间：患者整群自助法，B = 2,000；`RNGkind("Mersenne-Twister","Inversion","Rejection")`；**每个分析集开始前 `set.seed(20261110)`**；患者顺序与抽样方式与 AN_r1 `cluster_boot` 相同（`split(seq_len(n), as.character(pid))` 的水平顺序，`sample.int(P, P, replace = TRUE)`）。百分位法 type 7；不可算次数 >1%（>20）时 CI 记“不可估”；原样本不可算则点估计也不报。
4. 实现：本规格的估计量都是“患者内求和再相除”的比值或均值，按患者汇总充分统计量后重抽样，与逐行拼接数学上等价。**复现核对（运行门槛）**：用同一实现对 P 集重算 disc3、cut6.0_lab_only、mean_diff 的点估计与 CI，须与锁定 results.json 的值绝对差 ≤1e-12；不一致即停止，不写任何发表文件。
5. 小数字：比例的分子为 1–9，或“分母 − 分子”为 1–9 时，点估计与 CI 都不报，写 "<10"。计数取整到 10（1–9 写 "<10"，0 原样）。分析集总配对数与患者数只在差集（被剔除的配对数）≥10 时精确发表，否则只给取整值。
6. 全部输出标 “post hoc exploratory”；不做假设检验、不报 P 值；措辞为两种检测间的分类分歧，无参照标准。

## 1. C1：血气先入系统的配对中，按血气钾分箱的实验室钾 ≥6.0 比例

- **入系统先后字段**：MIMIC-IV `labevents.storetime`（BUILD_r1 写为 `gas_storetime`、`lab_storetime`）。lead = (lab_storetime − gas_storetime)，单位分钟。与 SAP §12 / AN_r1 `storetime_order_mimic` 同一定义。
- **分析集 C1** = P 中 lead > 0（血气先入系统）的配对，不重新配对。lead 缺失或 ≤0 的配对不进入（AN_r1 已知 missing = 0）。
- **分箱（运行前写定，按血气钾记录值）**：
  - B1：gas < 5.0
  - B2：5.0 ≤ gas < 5.5（记录精度 0.1 时即 5.0–5.4）
  - B3：5.5 ≤ gas < 6.0（即 5.5–5.9）
  - 另报 B1–B3 合并（gas < 6.0）。gas ≥ 6.0 的配对不在本项（已发表的条件比例覆盖）。
- **报告**（每箱及合并）：配对数、患者数（取整到 10）；实验室钾 ≥6.0 的配对数（取整）与比例（%，1 位小数；分子或补数 1–9 时不报）及整群自助法 95% CI（C1 集一次重抽样内同时计算各箱；某箱在某次重抽样中分母为 0 记不可算）；各箱 lead 中位数与 IQR（type 7，整数分钟；该箱配对 <100 时不报）。
- **43 分钟核对**：AN_r1 已有全部配对（missing = 0）lead 的 q25/q50/q75 = 34/43/57 分钟。本 run 重算：(a) 全部 P 集 lead 四分位数（须与锁定值相同，作为复现核对之一）；(b) C1 集内 lead 四分位数。稿件措辞固定为“两项结果写入信息系统的时间差中位数”，并写明“storetime 不代表医生实际看到结果或采取处置的时间，后两者未知”。
- 解释边界：只描述“血气结果先写入系统后，随后写入的实验室结果达到 ≥6.0 的频率”；不推断漏诊、仪器偏差或治疗后果；不把它说成预测值的临床建议。

## 3. C3：极端差值

- **定义（运行前写定）**：d = gas − lab。主定义 E2：|d| ≥ 2.0 mmol/L；次定义 E1：|d| ≥ 1.0 mmol/L。浮点比较用 |d| ≥ 阈值 − 1e-9。
- **C3a 集中程度（P 集）**，对 E2、E1 分别报告：极端配对数；含 ≥1 个极端配对的患者数；按患者极端配对数从多到少累加，达到全部极端配对 ≥50% 所需的最少患者数；有 ≥2 个极端配对的患者贡献的极端配对占比（%，整数）。计数取整到 10，比例按第 0.5 条小数字规则。
- **C3b 可核实的记录/配对特征（P 集）**，极端与非极端配对分别报告占比（%，整数，第 0.5 条规则）：d < 0（血气低于实验室）；两项 charttime 相同（signed_minutes = 0）；血气标本为动脉（specimen_class = ART）；任一结果带溶血备注；任一结果只靠时间关联住院（hadm 缺失）；任一钾值 < 1.5 或 > 10.0 mmol/L（数值层面可疑，用于提示录入/小数点问题；只计数，不判定）。单位：BUILD_r1 只保留 mEq/L 或 mmol/L（两者对钾等值），派生文件无单位字段，因此“单位换算错误”在保留记录中不可能由单位字段产生，只能通过上述数值范围间接提示；稿件照此写，不声称已逐条核实原始记录。
- **C3c 影响（新敏感性分析，post hoc，单独标注）**：分析集 X2 = P 去掉 E2 配对；X1 = P 去掉 E1 配对。每集报告：配对数与患者数（第 0.5 条）、mean_diff、disc3、cut6.0_lab_only、cut6.0_gas_only、cut6.0_gas_not_given_lab，点估计 + 整群自助法 CI；每集开始前重设种子。说明：按差值剔除是依据结局本身的选择，机械地降低分歧，只用于显示少数极端配对对均值和各比例的影响量级，不作为替代主分析；原分析保留不变。

## 5. 发表前防反推核验（SAP §17.1）

- 受保护量：本 run 任何新发表计数或可由发表值导出的差值中，真实值为 1–9 的量。包括：各箱 lab≥6.0 配对数；C1 集外（实验室先入系统或同时）lab≥6.0 且 gas<6.0 的配对数 L = （P 集 cut6.0_lab_only 分子）−（C1 合并分子）；X 集与 P 集之间被剔除配对中 disc3、lab_only、gas_only 的分子差；C3a/C3b 计数及其补数。
- 约束：本 run 的取整计数区间、百分比显示精度（含 CI 不计）与精确分母、锁定发表值（SHARE_r5：P 集 n、cut6.0 lab_only/gas_only 的百分比与取整分子、disc3 取整分子、storetime 先后取整计数）之间的加减关系。
- 方法：对每个受保护量，在上述约束下枚举全部整数可行解，求可行范围；**判定标准（同 SHARE_r5）：max − min ≥ 4**。不达标的量按以下顺序处理（不看估计值大小）：① 该量所在比例改为整数百分比；② 该量相关的计数改为只报 "<10"/不报；③ 仍不达标则该项整体不发表，在稿件写 “not shown (small numbers)”。
- verification.md 只写每个受保护量的可行宽度与处理结果，不写真实值。覆盖边界：非线性量（中位数、CI）不纳入。
